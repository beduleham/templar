# Templar Survivors

중세 판타지 오토배틀 서바이벌 게임 프로토타입.
15분을 버티면 승리한다. 이동만 조작하고 공격은 자동, 레벨업마다 3택으로 빌드를 쌓는다.

## 플레이

```
game/index.html 을 브라우저로 열면 끝. 빌드도 서버도 필요 없다.
```

| 조작 | |
| --- | --- |
| 이동 | `WASD` / 방향키 (모바일은 화면 드래그) |
| 직업 스킬 | `SPACE` (또는 우클릭) — 자원이 찼을 때 |
| 직업 선택 | `1`~`4` 또는 클릭 |
| 영혼의 제단 | `TAB` |
| 일시정지 | `ESC` / `P` |
| 음소거 | `M` |
| 재시작 | `SPACE` / `R` |

## 직업 — 위치 선정 규칙이 정반대다

성기사와 마법사는 **자세(stance)** 를 가진다. 같은 WASD로 정반대 행동을 하게 만드는 규칙이다.

### 🛡️ 성기사 — 「진영」 : 군중 속으로 파고든다

멈추면 **방벽**이 선다. 피해가 크게 줄고 체력이 돌아온다.
곁에 붙은 적 하나마다 **피해도 방어도 회복도 함께 오른다** (접전 ×14에서 피해 +119%, 피해 감소 -88%).
움직이면 방벽이 풀린다. → **군중 한가운데 자리를 잡고 버티는 게 최적이다.**

전용 특성: 강철 방벽 / **도발**(적을 끌어당긴다 = 더 강해진다) / 성전 / 가시 갑옷 / 불굴

### 🔮 마법사 — 「영창」 : 거리를 벌리고 멈춘다

멈추면 **영창 단계**가 오른다. 단계마다 피해 +26%, 쿨다운 -10%, 경험치 흡인 +160% (4단계에서 피해 +90%, 쿨다운 ×0.66).
주변의 적도 얼어붙고, **2단계부터는 날아오는 적 탄까지 느려진다**(서리 장막). 대신 발이 느리다.
움직이면 단계가 빠르게 빠진다. → **적을 떼어놓고 멈춰 서서 쏟아붓는 게 최적이다.**

전용 특성: 집중 영창 / 심층 마력 / 잔류 마력 / 비전 과부하 / 마력 폭주

### ⚔️ 전사 · 🗡️ 추적자

아직 자세가 없다. 자원 방식으로만 갈린다 —
전사 분노는 **처치할수록** 차고 가만있으면 감소, 추적자 집중은 **안 맞은 시간**에 비례한다.

| 직업 | 시작 무기 | 자원 | 스킬 |
| --- | --- | --- | --- |
| 🛡️ 성기사 | 성역 (신성) | 신앙 — 피격 시 충전 | 심판의 빛 |
| ⚔️ 전사 | 쇠사슬 플레일 (물리) | 분노 — 처치 시 충전 | 광전사의 돌진 |
| 🗡️ 추적자 | 투척 단검 (물리) | 집중 — 무피격 시간 비례 | 그림자 도약 |
| 🔮 마법사 | 마법 화살 (냉기) | 마나 — 시간 비례 | 비전 폭발 |

## 전직 — Lv10 · Lv22 · Lv34

전직하면 **능동 스킬이 통째로 바뀌고**, 자세 파라미터가 조정되며,
전용 특성 카드가 새로 열리고, 무기를 받기도 한다.
**1차 8 + 2차 16 + 3차 32 = 56전직**, 한 판에 **3번**.

전직마다 **전직의 징표 1개**를 소비하므로 끝까지 가려면 징표 3개가 필요하다.

3차는 **각성**이다. 수치가 아니라 규칙을 바꾼다 —
방벽이 이동 중에도 유지되거나(영원의 방벽), 영창이 항상 최대이거나(현자의 정점),
처치할 때마다 폭발이 번지거나(파멸의 술사), 중독된 적이 죽으면 역병이 퍼진다(역병의 화신).

끝까지 가면 시작 대비 **피해 ×1.0~3.7 · 체력 ×0.7~16.0** 으로 갈린다.
마법사가 갑주를 두르면(불괴의 룬갑) 체력 75 → 1,200 이 되고,
성기사가 방패를 버리면(사신) 체력은 줄지만 피해가 3.7배가 된다.

```
마법사 ─┬─ 마검사 ─────┬─ 마검성   ─┬─ 검마도 / 무념무상
        │              └─ 룬나이트 ─┴─ 룬 마스터 / 불괴의 룬갑
        └─ 원소술사 ───┬─ 대마법사 ─┬─ 현자의 정점 / 파멸의 술사
                       └─ 대현자   ─┴─ 시간의 주인 / 만물의 이치

성기사 ─┬─ 수호기사 ───┬─ 불멸의 성벽 · 성전사
        └─ 심판관 ─────┴─ 처형자 · 대심문관
전사   ─┬─ 광전사 ─────┬─ 전쟁군주 · 파괴자
        └─ 검투사 ─────┴─ 검성 · 투기장의 왕
추적자 ─┬─ 암살자 ─────┬─ 그림자 군주 · 독의 대가
        └─ 사냥꾼 ─────┴─ 명사수 · 야수 조련사
```

**마검사가 이 시스템의 핵심 예시다.** 마법사는 "멈춰야 강한" 직업인데,
마검사는 이동 중에도 영창이 남고 곁의 적에게 추가 피해를 준다 —
같은 자세를 정반대로 비튼다. 전직 하나로 플레이가 다시 뒤집힌다.

## 속성 조합

무기 8종에는 각각 속성이 하나씩 붙어 있다 (물리 · 화염 · 냉기 · 뇌전 · 신성 · 피).
**서로 다른 속성의 무기를 함께 들면 조합이 열린다.**

```
🔥 + ⚡  폭발 연쇄     처치 시 폭발이 번진다
❄️ + ⚔️  빙결 처형     둔화된 적이 받는 물리 피해 +45%
✨ + 🩸  흡혈 전환     가한 피해의 일부를 회복
🔥 + ✨  정화의 불길   모든 공격이 화상을 남긴다
⚡ + ❄️  감전 폭풍     둔화된 적이 죽으면 연쇄 번개
🩸 + ⚔️  학살         처치할수록 피해 누적 (최대 +35%)
```

조합 규칙은 타이틀 화면에 공개돼 있다 — 외우는 게임이 아니라 설계하는 게임이 되도록.
무기 슬롯은 6칸인데 무기는 8종이라, **무엇을 포기할지**가 곧 빌드다.

**조합에는 레벨 조건이 있다.** 무기를 모으기만 해서는 열리지 않는다.

| 단계 | 조건 | 효과 |
| --- | --- | --- |
| 발동 | 두 속성 무기가 **4레벨** 이상 | 조합 효과가 켜진다 |
| ★ 완성 | 두 속성 무기가 **8레벨**(최대) | 효과가 **1.7배** |

무기를 넓게 모으면 조합이 하나도 안 열리고, 좁게 키우면 완성까지 간다.
어느 쪽을 택할지가 빌드의 축이다.

조합이 지금 일하고 있는지가 화면에 보인다:

- 레벨업 카드에 **"이 무기를 들면 열리는 조합"** 이 금색으로 뜬다
- HUD 칩에 속성 아이콘과 **누적 발동 횟수**가 찍히고, 터질 때 점멸한다
- 무기 하나만 더 있으면 열리는 조합을 **점선 칩으로 힌트**

## 몬스터 — 17종 · 등급 3단계

스탯만 다른 게 아니라 **대응 방법이 다르다.**

| | 특징 |
| --- | --- |
| 🏹 사수 | 사거리에 들어오면 멈춰 쏜다. 붙거나 피해야 한다 |
| 💢 돌진자 | 예고선을 그린 뒤 직선 돌진. 읽고 비켜야 한다 |
| 🫧 분열체 | 죽으면 둘로 갈라진다 (2세대까지 — 한 마리가 최대 7마리) |
| 💣 폭발체 | 죽으면 터진다. 붙어서 잡으면 손해 |
| 🔮 주술사 | 싸우지 않고 주변을 회복·가속시킨다. 먼저 잡아야 할 표적 |
| 🛡️ 방패병 | 방패가 깨지기 전까지 피해의 75%를 막는다 |
| 🐺 사냥개 | 플레이어보다 빠르다. 도망칠 수 없다 |

**등급**은 같은 몬스터를 다른 상대로 만든다. 시간이 갈수록 상위 등급이 섞인다.

| 등급 | 체력 | 피해 | 경험치 | 표시 |
| --- | --- | --- | --- | --- |
| 일반 | ×1 | ×1 | ×1 | — |
| **정예** | ×5.5 | ×1.45 | ×4 | 금색 테두리 + 이름표, 35% 아이템 |
| **희귀** | ×15 | ×1.9 | ×10 | 보라 이중 테두리, 아이템 확정 + 회복 |

## 보스 — 5분 · 10분 · 15분, 각자 다른 문제

| | 패턴 |
| --- | --- |
| ☣️ **역병 군주** | 무리를 소환하고 **독 웅덩이**를 깐다 — 서 있을 자리를 빼앗는다 |
| 🪓 **강철 처형자** | 예고 후 **직선 돌진**, 착지 지점에 충격파 — 읽고 비켜야 한다 |
| 👁️ **심연의 왕** | **순간이동 + 방사형 탄막**, 체력 절반 아래에서 격노 |

## 맵 — 돌아다닐 이유

무한 평지가 아니다. 월드 격자마다 지형지물이 결정적으로 배치돼 있고,
화면 밖에 있으면 가장자리에 방향과 거리(m)가 표시된다.

| | 내용 |
| --- | --- |
| 🧰 보물 상자 | 소모품 1개 |
| ⛩️ 봉인된 제단 | **레벨 8 이상**에서 열린다. 다가가면 **파수꾼**이 깨어난다. 처치 시 **전직의 징표** (뒤에 여는 제단일수록 파수꾼이 단단하다) |
| 🗿 고대 비석 | 이번 판 동안 남는 영구 강화 |
| 🧱 석벽 | 이동을 막는다(불괴). 발사체는 통과 — 벽 뒤에서 쏘는 게 전술이 된다 |
| 🪨 바위 | 부술 수 있다. 부수면 보석과 소모품 |

**미니맵**(우하단)에 지형지물 · 징표 · 보스 · 적 밀도 · 벽이 함께 표시된다.
보스는 상단 체력바와 가장자리 화살표(거리 m)로 따로 강조된다.

**전직에는 징표가 필요하다.** 레벨만 채운다고 열리지 않는다 —
제단의 파수꾼이나 보스를 잡아 징표를 얻어야 하고, 전직할 때 1개를 소비한다.

## 소모품 — 3칸, `Q` 로 사용

💣 화염병 · ⏳ 시간의 모래 · 🧪 광란의 물약 · 🔰 수호의 부적 · 💠 영혼석

즉발형과 지속형이 섞여 있어 "언제 쓰느냐"가 판단이 된다.
소지품이 가득 차 있으면 주운 자리에서 즉시 사용된다.

## 영혼의 제단

판이 끝나면 처치 수와 생존 시간만큼 영혼을 얻고, 타이틀(`TAB`)의 제단에서 영구 강화를 산다.
브라우저를 닫아도 남는다.

## 밸런스

봇 시뮬레이션(4직업 × 3회 × 15분)으로 맞춘다. 현재 **네 직업 모두 2승 1패**,
죽는 시각이 3:29 · 3:39 · 5:09 · 7:33 로 흩어져 있다 —
한 구간에 몰리면 그건 곡선이 아니라 스파이크다.

| 직업 | 최저 HP | 15분간 피격 | 최종 레벨 |
| --- | --- | --- | --- |
| 성기사 | 46~57% | 223~249회 | 83~98 |
| 전사 | 44% | 21~43회 | 62~76 |
| 추적자 | 36~55% | 62~256회 | 93~137 |
| 마법사 | 28~30% | 482~497회 | 75~84 |

**단, 봇은 난이도의 하한선일 뿐이다.** 봇은 사람보다 카이팅을 잘한다 —
봇이 완주한다고 사람도 쉽다는 뜻은 아니지만, 봇이 죽는 지점은 사람에게도 확실히 어렵다.

## 기술 스택

의존성 없음. 파일 하나(`game/index.html`)에 HTML + Canvas 2D + WebAudio 만 들어 있다.
이미지·사운드 에셋을 쓰지 않고 전부 코드로 그리고 합성한다.

성능을 위해 넣은 것:

- **공간 해시** — 적 340마리 × 발사체를 전수 비교하지 않는다
- **오브젝트 풀링** — 발사체·파티클·보석을 미리 할당해 GC 정지를 없앤다
- **할당 없는 근접 탐색** — 상위 k개만 삽입 정렬로 유지 (적 340마리에서 update 0.53ms/프레임)
- **드로우 배칭** — 그림자와 보석 수백 개를 한 패스로
- **고정 타임스텝(1/60)** — 프레임률과 무관하게 밸런스가 재현된다

그래픽 에셋 교체 지점(`Sprites`)도 미리 만들어 뒀다.
아틀라스와 프레임 정의를 `Sprites.load()` 로 넘기면 도형 렌더링이 스프라이트로 바뀌고,
정의가 없는 적은 도형으로 폴백한다 — 하나씩 점진 교체가 가능하다.
