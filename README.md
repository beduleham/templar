# Templar Survivors

중세 판타지 오토배틀 서바이벌 게임 프로토타입.
15분을 버티면 승리한다. 이동만 조작하고 공격은 자동, 레벨업마다 3택으로 빌드를 쌓는다.

## 플레이

**https://beduleham.github.io/templar/game/** — 링크만 있으면 바로 된다.

`claude/vampire-survival-game-uosewa` 브랜치에 푸시하면
`.github/workflows/pages.yml` 이 자동으로 갱신한다.

```
game/index.html 을 브라우저로 열어도 된다. 빌드도 서버도 필요 없다.
```

| 조작 | |
| --- | --- |
| 게임 시작 | `SPACE` / 클릭 |
| 이동 | `WASD` / 방향키 (모바일은 화면 드래그) |
| 직업 스킬 | `SPACE` (또는 우클릭) — 자원이 찼을 때 |
| 직업 선택 | `1`~`4` 또는 클릭 |
| 영혼의 제단 | `TAB` |
| 일시정지 | `ESC` / `P` |
| 음소거 (효과음 + 음악) | `M` |
| 몬스터 이름표 | `N` |
| 재시작 | `SPACE` / `R` |
| 뒤로 (직업 선택 → 시작 화면) | `ESC` |

## 직업 — 위치 선정 규칙이 정반대다

성기사와 마법사는 **자세(stance)** 를 가진다. 같은 WASD로 정반대 행동을 하게 만드는 규칙이다.

### 🛡️ 성기사 — 「진영」 : 군중 속으로 파고든다

멈추면 **방벽**이 선다. 피해가 크게 줄고 체력이 돌아온다.
곁에 붙은 적 하나마다 **피해도 방어도 회복도 함께 오른다** (접전 ×14에서 피해 +119%, 피해 감소 -88%).
움직이면 방벽이 풀린다. → **군중 한가운데 자리를 잡고 버티는 게 최적이다.**

전용 특성: 강철 방벽 / **도발**(적을 끌어당긴다 = 더 강해진다) / 성전 / 가시 갑옷 / 불굴

스킬 「심판의 빛」은 **바라보는 방향으로 뻗는다**(사거리 520). 사방 폭발이면 어디를 보든
같아서 방향을 고를 이유가 없어진다 — 방패를 앞세워 밀고 들어가는 직업이라 넓이 대신 길이를 줬다.

### 🔮 마법사 — 「영창」 : 거리를 벌리고 멈춘다

멈추면 **영창 단계**가 오른다. 단계마다 피해 +26%, 쿨다운 -10%, 경험치 흡인 +160% (4단계에서 피해 +90%, 쿨다운 ×0.66).
주변의 적도 얼어붙고, **2단계부터는 날아오는 적 탄까지 느려진다**(서리 장막). 대신 발이 느리다.
사방 효과의 반경은 **넓이가 제곱으로 붙으므로** 일부러 좁게 잡았다 (냉기 46~82 · 장막 72~102).
초반에 약한 것이 이 직업의 컨셉이고, 무기 레벨로 그 대가를 되찾는다.
움직이면 단계가 빠르게 빠진다. → **적을 떼어놓고 멈춰 서서 쏟아붓는 게 최적이다.**

전용 특성: 집중 영창 / 심층 마력 / 잔류 마력 / 비전 과부하 / 마력 폭주

### ⚔️ 전사 · 🗡️ 추적자

아직 자세가 없다. 자원 방식으로만 갈린다 —
전사 분노는 **처치할수록** 차고 가만있으면 감소, 추적자 집중은 **안 맞은 시간**에 비례한다.

| 직업 | 시작 무기 | 자원 | 스킬 |
| --- | --- | --- | --- |
| 🛡️ 성기사 | 성역 (신성) | 신앙 — 피격 시 충전 | 심판의 빛 |
| ⚔️ 전사 | 쇠사슬 플레일 (물리) | 분노 — 처치 시 충전 | 광전사의 돌진 |
| 🗡️ 추적자 | 투척 단검 (물리) | 집중 — 무피격 시간 비례 | 그림자 도약 |
| 🔮 마법사 | 마법 화살 (냉기) | 마나 — 시간 비례 | 비전 폭발 |

## 전직 — Lv10 · Lv22 · Lv34

전직하면 **능동 스킬이 통째로 바뀌고**, 자세 파라미터가 조정되며,
전용 특성 카드가 새로 열리고, 무기를 받기도 한다.
**1차 8 + 2차 16 + 3차 32 = 56전직**, 한 판에 **3번**.

전직마다 **전직의 징표 1개**를 소비하므로 끝까지 가려면 징표 3개가 필요하다.

3차는 **각성**이다. 수치가 아니라 규칙을 바꾼다 —
방벽이 이동 중에도 유지되거나(영원의 방벽), 영창이 항상 최대이거나(현자의 정점),
처치할 때마다 폭발이 번지거나(파멸의 술사), 중독된 적이 죽으면 역병이 퍼진다(역병의 화신).

끝까지 가면 시작 대비 **피해 ×1.0~3.7 · 체력 ×0.7~16.0** 으로 갈린다.
마법사가 갑주를 두르면(불괴의 룬갑) 체력 75 → 1,200 이 되고,
성기사가 방패를 버리면(사신) 체력은 줄지만 피해가 3.7배가 된다.

```
마법사 ─┬─ 마검사 ─────┬─ 마검성   ─┬─ 검마도 / 무념무상
        │              └─ 룬나이트 ─┴─ 룬 마스터 / 불괴의 룬갑
        └─ 원소술사 ───┬─ 대마법사 ─┬─ 현자의 정점 / 파멸의 술사
                       └─ 대현자   ─┴─ 시간의 주인 / 만물의 이치

성기사 ─┬─ 수호기사 ───┬─ 불멸의 성벽 · 성전사
        └─ 심판관 ─────┴─ 처형자 · 대심문관
전사   ─┬─ 광전사 ─────┬─ 전쟁군주 · 파괴자
        └─ 검투사 ─────┴─ 검성 · 투기장의 왕
추적자 ─┬─ 암살자 ─────┬─ 그림자 군주 · 독의 대가
        └─ 사냥꾼 ─────┴─ 명사수 · 야수 조련사
```

**마검사가 이 시스템의 핵심 예시다.** 마법사는 "멈춰야 강한" 직업인데,
마검사는 이동 중에도 영창이 남고 곁의 적에게 추가 피해를 준다 —
같은 자세를 정반대로 비튼다. 전직 하나로 플레이가 다시 뒤집힌다.

## 속성 조합

무기 8종에는 각각 속성이 하나씩 붙어 있다 (물리 · 화염 · 냉기 · 뇌전 · 신성 · 피).
**서로 다른 속성의 무기를 함께 들면 조합이 열린다.**

```
🔥 + ⚡  폭발 연쇄     처치 시 폭발이 번진다
❄️ + ⚔️  빙결 처형     둔화된 적이 받는 물리 피해 +45%
✨ + 🩸  흡혈 전환     가한 피해의 일부를 회복
🔥 + ✨  정화의 불길   모든 공격이 화상을 남긴다
⚡ + ❄️  감전 폭풍     둔화된 적이 죽으면 연쇄 번개
🩸 + ⚔️  학살         처치할수록 피해 누적 (최대 +35%)
```

조합 규칙은 타이틀 화면에 공개돼 있다 — 외우는 게임이 아니라 설계하는 게임이 되도록.
무기 슬롯은 6칸인데 무기는 8종이라, **무엇을 포기할지**가 곧 빌드다.

**조합에는 레벨 조건이 있다.** 무기를 모으기만 해서는 열리지 않는다.

| 단계 | 조건 | 효과 |
| --- | --- | --- |
| 발동 | 두 속성 무기가 **4레벨** 이상 | 조합 효과가 켜진다 |
| ★ 완성 | 두 속성 무기가 **8레벨**(최대) | 효과가 **1.7배** |

무기를 넓게 모으면 조합이 하나도 안 열리고, 좁게 키우면 완성까지 간다.
어느 쪽을 택할지가 빌드의 축이다.

조합이 지금 일하고 있는지가 화면에 보인다:

- 레벨업 카드에 **"이 무기를 들면 열리는 조합"** 이 금색으로 뜬다
- HUD 칩에 속성 아이콘과 **누적 발동 횟수**가 찍히고, 터질 때 점멸한다
- 무기 하나만 더 있으면 열리는 조합을 **점선 칩으로 힌트**

## 무기 성장 곡선 — 마법 계열은 늦게 핀다

대부분의 무기는 레벨마다 1.3배씩 고르게 오른다. 그러면 숫자만 커지고
1레벨이나 8레벨이나 **체감이 같다.**

마법 계열(🔮 마법 화살 · ⚡ 천벌의 번개)만 다른 곡선을 쓴다. 피해뿐 아니라
**탄 크기 · 관통 · 낙뢰 반경**까지 레벨에 묶어, 초반엔 확실히 약하고 후반에 비약한다.

초당 피해 실측 (더미 70마리 밀집 · 광역에 유리한 조건):

| 무기 | Lv1 | Lv4 | Lv6 | Lv8 |
| --- | --- | --- | --- | --- |
| 🗡️ 투척 단검 | 43 | 321 | 964 | 3,915 |
| 🔥 불꽃 파도 | 168 | 606 | 1,240 | 2,145 |
| 🔮 **마법 화살** | **29** | 142 | 1,273 | **9,856** |
| ⚡ **천벌의 번개** | **26** | 444 | 3,277 | **26,774** |

1~3레벨에서 가장 약한 대신 성장 배율이 100배 넘게 크다.
**무엇을 끝까지 키울지**가 마법사의 빌드 설계가 된다.

## 전리품 — 모든 적이 보석을 떨구지는 않는다

처치할 때마다 100% 보석이 나오면 **처치 수가 곧 경험치**가 되고 화면이 보석으로 덮인다.
확률로 바꾸면 "무엇을 잡느냐"가 의미를 갖는다.

| 직업 | 전리품 확률 | 왜 |
| --- | --- | --- |
| 🛡️ 성기사 | **11%** | 군중을 통째로 쓸어 담는다 — 한 마리당 값은 가장 낮다 |
| 🔮 마법사 | **15%** | |
| ⚔️ 전사 | **16%** | |
| 🗡️ 추적자 | **21%** | 약탈에 능하다 — 같은 수를 잡아도 두 배 가까이 건진다 |

확률이 낮은 만큼 **한 알이 크다.** 확률만 내리면 성장이 굶는다 —
실제로 10%대로 내렸더니 전사가 4분 동안 1레벨에 묶인 채 적이 68 → 244마리로 불어나 죽었다.
낮은 확률은 "적게 주는 것"이 아니라 **"뭉쳐서 주는 것"** 이어야 한다.
다만 완전히 상쇄하면 직업 특성이 사라지므로, 확률이 높은 직업이 총량에서도 조금 유리하다
(성기사 0.88배 · 추적자 1.14배).

**정예·희귀 등급과 보스·파수꾼은 확률과 무관하게 반드시 떨군다.** 그건 사냥이 아니라 사건이다.
영혼의 제단 「탐욕」은 획득량뿐 아니라 이 확률도 올려준다.

## 몬스터 — 17종 · 등급 3단계

스탯만 다른 게 아니라 **대응 방법이 다르다.**

| | 특징 |
| --- | --- |
| 🏹 사수 | 사거리에 들어오면 멈춰 쏜다. 붙거나 피해야 한다 |
| 💢 돌진자 | 예고선을 그린 뒤 직선 돌진. 읽고 비켜야 한다 |
| 🫧 분열체 | 죽으면 둘로 갈라진다 (2세대까지 — 한 마리가 최대 7마리).\n갈라진 몸은 **부모 경험치의 8%**만 준다 — 분열로 처치 수를 불려 경험치를 버는 길은 막혀 있다 |
| 💣 폭발체 | 죽으면 터진다. 붙어서 잡으면 손해 |
| 🔮 주술사 | 싸우지 않고 주변을 회복·가속시킨다. 먼저 잡아야 할 표적 |
| 🛡️ 방패병 | 방패가 깨지기 전까지 피해의 75%를 막는다 |
| 🐺 사냥개 | 플레이어보다 빠르다. 도망칠 수 없다 |

**등급**은 같은 몬스터를 다른 상대로 만든다. 시간이 갈수록 상위 등급이 섞인다.

| 등급 | 체력 | 피해 | 경험치 | 표시 |
| --- | --- | --- | --- | --- |
| 일반 | ×1 | ×1 | ×1 | — |
| **정예** | ×5.5 | ×1.45 | ×4 | 금색 테두리 + 이름표, 35% 아이템 |
| **희귀** | ×15 | ×1.9 | ×10 | 보라 이중 테두리, 아이템 확정 + 회복 |

## 보스 — 5분 · 10분 · 15분, 각자 다른 문제

보스가 그냥 체력 큰 적이면 "계속 때린다"가 유일한 답이 된다.
**미션**이 그 답을 잠시 막아 판단할 거리를 만든다 — 미션이 살아 있는 동안
보스는 받는 피해가 **82% 줄어든다.**

| | 미션 | 패턴 |
| --- | --- | --- |
| ☣️ **역병 군주** | 역병의 뿌리 3개를 부숴라 | 무리 소환 · 독 웅덩이 · **예고 후 대형 범위기**. 뿌리가 살아 있으면 **초당 1.8% 회복** |
| 🪓 **강철 처형자** | 철벽을 부수고 빠져나가라 | 수정 5개로 **가둔 뒤** 돌진(가둔 동안 돌진 주기 45% 단축) · 착지 지점에 기둥을 세워 자리를 좁힌다 |
| 👁️ **심연의 왕** | 공허의 기둥 4개를 부숴라 | 순간이동 + 방사형 탄막 · 체력 절반에서 **격노하며 기둥을 다시 세운다** |

기둥은 수정이라 **왕의 탄막도 튕겨낸다.** 무엇을 먼저 부술지가 곧 전략이 된다.
예고 범위기는 바닥에 원이 차오르며 표시되므로 읽고 빠질 수 있다.

## 맵 — 돌아다닐 이유

무한 평지가 아니다. 월드 격자마다 지형지물이 결정적으로 배치돼 있고,
화면 밖에 있으면 가장자리에 방향과 거리(m)가 표시된다.

| 🦴 거대 유해 | 막음 | 통과 | ○ | 30~126 | 갈비뼈 사이로 탄이 지나간다 |
| 🗼 첨탑 | 막음 | **막음** | ✕ | 18~49 | 가장 높다 — 멀리서도 보이는 이정표 |
| 🔥 화톳불 | **통과** | 통과 | ○ | 12~23 | **곁의 적을 태운다** — 적을 끌고 오면 자산이 된다 |
| 🌊 늪 | **통과** | 통과 | ✕ | 34~83 | **모두가 절반 속도** — 플레이어도 적도 |

**같은 종류 안에서도 크기가 크게 다르다.** 제곱 분포로 뽑아 작은 것이 흔하고
큰 것이 드물게 하고, 6% 확률로 **1.75배 '거대'** 가 서서 지형의 이정표가 된다.
큰 것일수록 단단하다 — 보이는 것과 체감이 어긋나면 안 된다.

수정 기둥은 양날이다. 적의 탄막을 막아주기도 하지만, 내 유도탄이 튕겨 돌아오기도 한다.
화톳불과 늪은 반대로 **이용하는** 지형이다 — 적을 화톳불로 끌고 가거나, 늪에 빠뜨려 떼어놓는다.

| 🧰 보물 상자 | 소모품 1개 |
| ⛩️ 봉인된 제단 | **레벨 8 이상**에서 열린다. 다가가면 **파수꾼**이 깨어난다. 처치 시 **전직의 징표** (뒤에 여는 제단일수록 파수꾼이 단단하다) |

**미니맵**(우하단)에 지형지물 · 징표 · 보스 · 적 밀도 · 벽이 함께 표시된다.
보스는 상단 체력바와 가장자리 화살표(거리 m)로 따로 강조된다.

**각성은 4차까지 있고, 세 가지를 모두 충족해야 열린다.**

| | 레벨 | 시각 | 징표 |
| --- | --- | --- | --- |
| 1차 | 8 | **3:00** | 1개 |
| 2차 | 20 | **6:00** | 2개 |
| 3차 | 34 | **9:00** | 3개 |
| 4차 · 초월 | 52 | **12:00** | 4개 |

시각은 판 전체 길이의 1/5 · 2/5 · 3/5 · 4/5 지점이다 — 고정 숫자가 아니라 비율이라
판 길이를 바꾸면 함께 따라간다. 경험치 배율을 조절할 때마다 각성 시점이 흔들리지
않도록 시간에 묶어 뒀다.

**4차 초월은 직업당 3종.** 3차 최종형이 32종이라 경로마다 붙이면 데이터가 64개가 되고
하나하나가 얕아진다 — 갈래 수보다 무게를 택했다.

**징표도 단계만큼 필요하다.** 레벨과 시간을 채운다고 열리지 않는다 —
제단의 파수꾼이나 보스를 잡아 징표를 얻어야 하고, 전직할 때 1개를 소비한다.

## 소모품 — 3칸, `Q` 로 사용

**처치 수가 아니라 시간으로 나온다.** 확률로만 두면 후반에 분당 수백 마리를 잡으면서
소모품도 분당 수백 개가 된다(실측 593개/분). 그러면 3칸은 늘 가득 차 있고
"언제 쓸까"라는 판단이 사라진다.

- 정예·희귀는 **확률을 굴릴 자격**만 얻고, 실제로 나올지는 재사용 대기가 정한다
- **소모품(20초)과 회복(6초)은 다른 손잡이다.** 같이 조였더니 완주율이 46% → 21% 로 떨어지고
  사망이 첫 보스(5:00)에 몰렸다 — 소지품에 쌓이는 물건과 생존의 기반을 한 값으로 묶으면 안 된다
- 일반 몹은 10초 대기에 0.4% — 주 공급원은 아니지만 완전히 끊지는 않는다
- **보스 · 파수꾼 · 상자 · 비석은 대기와 무관하게 확정** — 그건 사냥이 아니라 사건이다

결과: 분당 593개 → **9.9개**, 그중 **61%가 정예·희귀·보스·파수꾼**에서 나온다.

즉발형과 지속형이 섞여 있어 "언제 쓰느냐"가 판단이 된다.

## 음악 — 파일 없이 합성한다

에셋을 쓰지 않는 게 이 프로젝트의 규칙이라 음악도 WebAudio 로 만든다.

시작 화면과 전투가 같은 세계로 들려야 한다.

## 메인 화면 — 회화 한 장, 그 위에 픽셀 UI

인트로와 직업 선택의 배경은 손그림 회화 한 장이다(1600×900 JPEG, 317KB, data URI 내장).
아틀라스에는 넣지 않는다 — 아틀라스는 128칸 격자에 맞춰 확대 없이 찍는 픽셀 그림판이고
이건 화면을 덮도록 늘려 그리는 회화라, 규칙이 반대다.

글자가 읽히도록 문지르는 겹을 두 장 깐다: 세로 그러데이션 + **가운데 줄기 한 겹**.
글자는 가운데에 모여 있으므로 화면 전체를 누를 이유가 없다 — 좁게 누르면 좌우의 그림이
그대로 남는다. 너무 누르면 그림이 사라지고 덜 누르면 글자가 먹히므로,
`tests/main-bg.js` 가 **글자 대비**와 **가장자리의 결**(평평해지면 0에 가까워진다)을 함께 잰다.

판 안에서는 쓰지 않는다. 게임 화면은 여전히 픽셀이다.

넓은 화면의 첫 화면은 **가운데를 비운다** — 왼쪽에 직업 목록(눌러서 바로 고른다),
오른쪽에 설명 넉 줄, 가운데 아래에 버튼 셋, 가운데는 그림. 그림은 1.55배 당겨
인물의 발밑을 화면 바닥에 맞춘다. 처음에는 문지르는 겹이 셋이나 곱해져
`(1-.52)·(1-.32)·(1-.42) = .19`, **그림의 19% 만 남아 있었다** — 겹을 줄인 게 아니라
글자를 겹 밖으로 옮겨서 풀었다. 좁은 화면은 그 자리가 없으므로 예전대로 깊게 누른다.

## 메뉴 UI — 늘리는 법이 조각마다 다르다

버튼 · 액자 · 창틀 · 가름줄 · 직업 문장 넷 · 제목 로고까지 열셋을 손그림으로 받았다.
셋 다 늘려 그리지만 늘리는 법이 다르다.

| 조각 | 늘리는 법 | 왜 |
|---|---|---|
| 버튼 판 | 가로 삼등분 (`drawSliceH`) | 세로는 고정, 끝 장식은 비율을 지켜야 한다 |
| 금 액자 · 돌 창틀 | 아홉 조각 (`drawSlice9`) | 가로세로가 다 변한다 |
| 가름줄 | 통째로, 비율만 (`uiArtW`) | 장식이 **가운데** 있어 삼등분하면 뭉갠다 |
| 로고 | 칸에 맞춰 넣기 (letterbox) | 글자는 1% 만 틀어져도 보인다 |

배경은 마젠타가 아니라 **순수 초록**으로 받는다 — 마젠타 규칙은 마법사 문장의 보라색을
통째로 지운다. 로고 시트만 짙은 초록(4,23,15)으로 와서 규칙에 안 걸렸고, 오류 없이
초록 사각형이 제목 뒤에 실렸다. 화면을 안 봤으면 못 잡았을 종류라 `tests/ui-parts.js`
가 부품 안과 첫 화면의 남은 초록을 함께 센다. 자세한 것은 [§107](docs/art-spec.md).

## 신앙 ↔ 타락 — 매 판 성인이 되거나 괴물이 된다

저울 하나가 −100(타락)에서 +100(신앙) 사이를 오간다. **레벨업에서 무엇을 고르느냐**가
저울을 민다 — 무기는 속성이 정하고(신성·냉기 +, 피·화염 −, 물리·뇌전 0), 능력은
「**지키는 것은 신앙, 죽이고 빼앗는 것은 타락**」이 정한다(방어구·재생·활력 +,
위력·신속·탐욕 −). 새로 얻으면 무기 12·능력 8, 강화면 그 절반. 문턱은 32와 64다.

처음에는 무기 속성만 읽었는데, 봇 4직업을 재 보니 20분 뒤 저울이 ±18 까지밖에 안 갔다.
문턱이 ±40 이라 **계단이 한 번도 안 바뀌었다** — 은혜도 저주도 배너도 한 번도 켜진 적이
없었다. 사람이 「있는지조차 몰랐다」고 한 게 화면 문제가 아니라 이것이었다.

양 끝에서 큰 힘과 그만한 저주가 **함께** 온다.

| 계단 | 은혜 | 저주 |
| --- | --- | --- |
| 신앙 | 받는 피해 −8% | 이동 −6% |
| 성인 | 받는 피해 −15% · 큰 한 방 무효화(15초) | 이동 −18% |
| 타락 | 피해 +10% · 처치마다 회복 | 최대 체력 −6% |
| 괴물 | 피해 +22% · 처치마다 큰 회복 | 최대 체력이 30초마다 −2% (40%까지) |

**신앙의 대가가 이동인 것**과 **타락의 대가가 시간에 비례하는 것**이 요점이다. 이동은
이 게임의 유일한 조작이라 가장 무거운 값이고, 타락은 「지금 세지고 나중에 죽는다」여야
고정 감소보다 재미있다.

**각성 68갈래가 이 저울의 척추다.** 각성 화면은 늘 둘(4차는 셋) 중 하나라, 형제 중
지키는 쪽이 신앙(+16, 4차 +24)이고 빼앗는 쪽이 타락이다. 32개 갈림길이 전부 진짜
갈림길이라 어느 직업으로도 각성만으로 ±72 까지 간다 — 각성이 계단을 정하고 레벨업이
다듬는다. 갈래를 **막지는 않는다**(후보가 비면 각성이 아예 안 열린다). 성향은 `mods` 와
`stanceMod` 에서 같은 규칙으로 뽑는다 — 최대 체력·방어·재생은 지키는 것, 피해·치명타·
즉사·흡혈·중독은 빼앗는 것.

저울은 네 자리에서 말한다. **카드 맨 위 띠**가 고르기 전에 「신앙 +8 / 신앙에 이른다」를
말하고(사후 통보면 저울이 아니라 벌이다), 문턱을 넘는 순간 **제 배너**가 이름과 은혜와
「그 대가로 …」를 함께 띄우며, **HUD 저울**이 지금 계단의 은혜 한 줄·대가 한 줄을 늘
달고 있고, **화면 가장자리**가 금빛과 핏빛으로 물든다(가운데는 §101 을 지켜 안 건드린다).
넷이 전부 같은 함수(`faithOf`)와 같은 문구 표를 보므로 서로 갈릴 수 없고, 회귀가 그
약속을 잰다.

## 죄의 표식 — 무리가 아니라 표적을 사냥한다

언제나 세 마리가 죄 표식을 달고 있다. 잡으면 큰 경험치와 소모품, 그리고 판 밖으로
나가는 영혼이 나온다. **징표는 안 준다** — 각성이 3·6·9·12분에 레벨과 징표를 함께
요구하도록 맞춰 둔 리듬이라, 표식이 징표를 흘리면 그게 무너진다.

**죄인은 다가오지 않는다.** 처음엔 표식만 칠했더니 8분 판에서 표식이 죽은 자리가
67~93px 이었다 — 찾아간 게 아니라 걸어온 것을 잡았다. 이 게임의 적은 전부 플레이어에게
모이므로 색만 입히면 장식이다. 그래서 죄인은 340~900 에 그대로 서서 맴돌고, 잡으려면
**안전한 자리를 떠나야 한다.** 고친 뒤 봇의 처형이 78 → 9 로 떨어졌는데 그게 옳은
신호다 — 의도 없이 얻을 수 없어야 표적이다.

**그리고 처형이 무엇을 줬는지 말한다.** 오래도록 보상은 다 주면서 아무 말도 안 했다 —
보석은 다른 처치에서도 쏟아지고, 소모품은 42px 옆에 조용히 놓이고, 연출 타이머
(`Sin.flash`)는 켜 두기만 하고 **읽는 데가 한 군데도 없었다.** 지금은 세 자리가 같은
숫자를 말한다: 처치 지점의 「+3 영혼 / 경험치 ×6」, 알림 큐의 띠, 그리고 HUD 의
「처형 n · 영혼 +3n」. 켜기만 한 값은 아무 오류도 안 내고 아무 일도 안 하므로,
회귀가 세 채널이 다 살아 있는지를 잰다.

설계와 숫자는 [`docs/hook-spec.md`](docs/hook-spec.md), 회귀는 `tests/sin-mark.js`.

## 성전 기록 — 68갈래를 계보로 모은다

전직 68갈래는 한 판에 최대 네 번, 그것도 한 직업일 때만 보이고 사라졌다. **초상 51장을
그려 놓고 아무도 모으고 있지 않았다.** 도달한 갈래를 영구히 남기고 초상에 불을 켠다.

직업 하나씩 **2 → 4 → 8 → 3** 의 나무로 편다. 부모와 자식을 잇는 선은 **둘 다 도달했을
때만** 불이 들어온다. 못 간 갈래도 이름은 보여준다 — 이 게임에는 68갈래가 무엇인지 볼
방법이 달리 없어서, 기록이 전리품 상자이자 길잡이여야 한다.

**능력치 보상은 안 붙인다.** 수집이 세지면 안 모은 사람이 불리해지고, 이 장르에서 그건
신규 진입을 막는 벽이 된다. 첫 화면에서 `C`, 제단 화면 오른쪽 위 버튼으로 연다.

**화면이 다음 판의 목표를 말한다.** 「68 중 30」은 목표가 아니라 벽이다. 한 판은
1→2→3차 한 줄과 4차 하나를 걷고 줄은 직업마다 여덟뿐이라, 안 걸어 본 칸이 가장 많은
줄이 곧 다음 판의 목표다 — 「다음 판에 3칸이 새로 열린다 — 수호기사 → 불멸의 성벽 →
영원의 방벽 · 신의 성벽」. 그 칸들은 점선 테와 「다음」 꼬리표로 표시한다. 능력치는
여전히 아무것도 안 준다. 주는 것은 어디로 갈지뿐이다. 회귀가 **길잡이만 따라가면
정말 다 채워지는지**를 잰다(네 직업 모두 8판, 막다른 곳 없음) — 막다른 길잡이는
거짓말이다. 짚은 칸에는 최초 도달 날짜와 시각도 뜬다(처음부터 적고 있었는데 읽는
데가 없었다).

**화면은 「이름이 사람 눈에 몇 px 인가」로 짠다.** 처음에는 이름이 초상 위에 겹쳐 앉았고,
배율 상한이 1이라 1280x720 에서 화면의 3분의 1이 비는데도 칸이 98px 로 남았고, 좁은
화면에서는 3차 여덟 칸을 가로에 우겨넣느라 이름이 6px 이 됐다 — 글자가 아니라 무늬였다.
지금은 이름이 제 판 위에 앉고, 남는 자리만큼 칸이 커지고(1.7배까지), 이름이 9.5px 아래로
내려갈 화면에서는 나무를 접고 **차수 하나씩** 본다(격자 열 수는 칸이 가장 커지는 쪽으로 —
세로 폰 2열, 가로 폰 4열). 「좁다」를 논리 폭으로 판단하면 안 된다 — 가로 폰은 논리 폭이
1410 이지만 844px 로 줄여 그려서 11px 글자가 7px 로 보인다. 회귀가 `ctx.fillText` 를
가로채 실제 css px 를 잰다.

## 효과음 — 소리에도 자리와 예산이 있다

계측해 보니 10분 화면에서 **피격 10,504건 중 소리가 난 건 121건**이었고,
그 121건이 전부 모노였다. 900px 밖에서 터진 폭발이 발밑 폭발과 같게 들렸다는 뜻이다.

그래서 소리를 층으로 나눴다.

| 층 | 자리 | 예산 |
| --- | --- | --- |
| 안내음 (레벨업 · 전직 · 제단 · 메뉴) | 가운데 | 없음 — 늘 들린다 |
| 내 소리 (무기 · 피격 · 획득) | 가운데 | 없음 — 늘 들린다 |
| 판 소리 (타격 · 처치 · 적 탄 · 폭발) | **월드 좌표** | 동시 14개까지 |

판 소리는 화면 밖(880px)이면 아예 울리지 않고, 가까울수록 크고, 좌우로 갈린다.
적이 많아질수록 간격이 벌어진다 — 타격 85→260ms, 처치 170→420ms(적 0→300).
이 손잡이 없이 모든 무기에 타격음을 달았더니 10분에 **초당 89개**가 울렸다.
그건 신호가 아니라 안개다.

무기 8종이 각자 다른 발사음을 낸다(예전엔 3종만, 그 셋도 같은 700Hz였다).
때리는 소리에는 대역 통과 잡음을 한 겹 얹었다 — 오실레이터 하나로는 '삑'이지 '퍽'이 아니다.
중요한 소리는 볼륨을 올리는 대신 **음악을 잠깐 눌러** 자리를 낸다.

`master` 뒤에 리미터를 뒀다. 세기가 두 배가 됐는데도 깎임은 여전히 0%다.

```sh
node tests/tools/measure-audio.js after   # 울린 소리를 오프라인으로 다시 렌더해 파형을 잰다
```

## 그래픽 리소스 — 그림 도구 없이 코드로 찍는다

몬스터 17종이 **픽셀 스프라이트**로 그려진다. 그림 파일을 따로 두지 않고
`art/make-sprites.js` 가 1픽셀씩 `fillRect(1,1)` 로 찍어 만든다 —
안티에일리어싱이 전혀 없어야 `imageSmoothingEnabled = false` 와 맞는다.

**실루엣은 6종뿐이다.** 17종은 거기에 색만 갈아 끼운 것이고,
그 색은 `ENEMY_TYPES[*].color` 에서 그대로 가져오므로
미니맵·피격 파티클·체력바와 어긋날 수 없다.

| 실루엣 | 쓰는 몬스터 | 애니메이션 |
| --- | --- | --- |
| `blob` | 슬라임 · 분열체 · 폭발체 | 눌렸다 펴진다 |
| `bat` | 박쥐 | 날개가 위아래로 |
| `ghost` | 유령 · 사신 · 주술사 | 떠오르고 아랫자락이 물결친다 |
| `humanoid` | 좀비 · 괴수 · 사수 · 돌진자 · 방패병 | 팔다리가 번갈아 |
| `hound` | 사냥개 | 네 다리가 달린다 |
| `boss` (64px) | 파수꾼 · 보스 3종 | 숨 쉬듯 오르내린다 |

아틀라스는 **data URI 로 내장**돼 있다(약 320KB). 아티팩트가 외부 파일을 실을 수 없어서다.

**전직 카드에는 갈래마다 전신 초상 한 장**이 붙는다 — 그 갈래까지의 혈통 장비를 전부 입은 모습이라
"고르면 이렇게 된다"가 한눈에 든다. 성기사 · 전사 · 추적자 각 17 이 들어갔고(51/68), 아직 없는 갈래는
절차로 그린 겹(망토·머리 장식·궤도·문양)으로 떨어진다.
로드에 실패해도 도형 렌더링으로 계속 돌기 때문에 깨질 일이 없다.

```sh
node art/make-sprites.js   # 스프라이트 재생성 → art/atlas.png · atlas-frames.json · atlas.b64
node art/make-guide.js     # Piskel 용 픽셀 도안
```

### 아틀라스는 WebP 무손실 한 장

파일의 90% 가 아틀라스였다(9.67MB 중 8.70MB — 코드는 7% 뿐이다). WebP 무손실로
바꿔 **9.67 → 6.39MB**, 바뀐 픽셀은 0. 다만 WebP 는 한 변이 16383px 을 못 넘어서
512×16640 이던 아틀라스를 먼저 재묶어야 했다(`art/repack-atlas.py` — 빈 줄 11.2% 를
띠 단위로 걷어내 512×14784). 손실 압축은 절반을 더 줄여 주지만 픽셀 실루엣을 따라
자홍색 테가 돌고 바닥 타일의 결이 뭉개져서 안 쓴다.

손으로 그린 그림으로 교체하려면 **[docs/art-spec.md](docs/art-spec.md)** 의 규격을 따르면 된다.

## 기술 스택

의존성 없음. 파일 하나(`game/index.html`)에 HTML + Canvas 2D + WebAudio 만 들어 있다.
이미지·사운드 에셋을 쓰지 않고 전부 코드로 그리고 합성한다.

성능을 위해 넣은 것:

- **공간 해시** — 적 340마리 × 발사체를 전수 비교하지 않는다
- **오브젝트 풀링** — 발사체·파티클·보석을 미리 할당해 GC 정지를 없앤다
- **할당 없는 근접 탐색** — 상위 k개만 삽입 정렬로 유지 (적 340마리에서 update 0.53ms/프레임)
- **드로우 배칭** — 그림자와 보석 수백 개를 한 패스로
- **고정 타임스텝(1/60)** — 프레임률과 무관하게 밸런스가 재현된다

그래픽 에셋 교체 지점(`Sprites`)도 미리 만들어 뒀다.
아틀라스와 프레임 정의를 `Sprites.load()` 로 넘기면 도형 렌더링이 스프라이트로 바뀌고,
정의가 없는 적은 도형으로 폴백한다 — 하나씩 점진 교체가 가능하다.
