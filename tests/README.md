# 회귀 테스트

브라우저를 띄워 실제로 렌더링되는지까지 확인하는 테스트다.

```sh
npm i playwright        # 최초 1회
node tests/regress-freeze.js
```

## regress-freeze.js

**잡는 버그:** 마법사로 천벌의 번개를 얻어 「감전 폭풍」 조합이 해금된 직후
레벨업 화면이 그려지지 않고 게임이 멈추던 문제.

원인은 `drawHUD()` 안에서 `const overlay` 를 **사용 지점보다 뒤에** 선언한 것이었다.
조합 해금 배너(`Game.comboFlash > 0`)가 뜨는 프레임에만 TDZ 예외가 나서,
`drawHUD()` 이후의 `drawLevelUp()` 이 통째로 건너뛰어졌다.
게다가 배너 타이머를 `update()` 안에서 줄이고 있었는데 `update()` 는 레벨업 화면에서
돌지 않으므로, 한 번 걸리면 **영원히** 풀리지 않았다.

테스트는 화면에 "LEVEL UP!" 픽셀이 실제로 찍히는지까지 본다 —
예외를 삼키고 검은 화면을 그리는 회귀를 잡기 위해서다.
