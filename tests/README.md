# 회귀 테스트

브라우저를 띄워 실제로 렌더링되는지까지 확인하는 테스트다.

```sh
npm i playwright        # 최초 1회
node tests/regress-freeze.js
```

## regress-freeze.js

**잡는 버그:** 마법사로 천벌의 번개를 얻어 「감전 폭풍」 조합이 해금된 직후
레벨업 화면이 그려지지 않고 게임이 멈추던 문제.

원인은 `drawHUD()` 안에서 `const overlay` 를 **사용 지점보다 뒤에** 선언한 것이었다.
조합 해금 배너(`Game.comboFlash > 0`)가 뜨는 프레임에만 TDZ 예외가 나서,
`drawHUD()` 이후의 `drawLevelUp()` 이 통째로 건너뛰어졌다.
게다가 배너 타이머를 `update()` 안에서 줄이고 있었는데 `update()` 는 레벨업 화면에서
돌지 않으므로, 한 번 걸리면 **영원히** 풀리지 않았다.

테스트는 화면에 "LEVEL UP!" 픽셀이 실제로 찍히는지까지 본다 —
예외를 삼키고 검은 화면을 그리는 회귀를 잡기 위해서다.

## regress-pools.js

**잡는 버그 2개** (둘 다 오브젝트 풀이 가득 차면 `alloc()` 이 조용히 실패하던 것):

1. **40레벨 이후 처치해도 경험치가 안 나온다** — 보석 풀(700)이 못 주운 보석으로
   가득 차서 새 보석이 스폰되지 않았다.
   → 가득 차면 플레이어에게서 가장 먼 보석을 재활용하고 그 값을 넘겨받는다(총량 보존).
2. **파수꾼·보스를 잡아도 전직의 징표가 안 나온다** — 획득물 풀(24)이 못 주운
   회복/자석으로 가득 차서 징표 스폰이 실패했다.
   → 풀을 72로 늘리고, 징표·소모품은 자리가 없으면 가장 먼 회복/자석을 밀어내고
   놓는다. 징표는 절대 밀려나지 않는다.

테스트는 1,400회 처치로 풀을 **실제로 포화시킨 뒤**,
그 상태에서 경험치 총량이 늘어나는지 / 플레이어 근처에 새 보석이 생기는지 /
파수꾼과 보스가 징표를 주는지 / 이후 400회를 더 처치해도 징표가 유지되는지를 본다.

이 버그들은 초반에는 절대 안 나타난다. 후반 상태를 만들어 놓고 테스트해야 잡힌다.
